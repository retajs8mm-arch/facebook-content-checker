# 🛡️ درع الأحرار - Facebook Content Checker

**أداة فحص محتوى الفيسبوك الشاملة والقوية**

## نبذة عن الأداة

أداة متقدمة لفحص المنشورات والصفحات على الفيسبوك بحثاً عن المخالفات والمحتوى الخطير بدعم الذكاء الاصطناعي.

### الميزات الرئيسية ✨

- ✅ **فحص شامل للمنشورات** - فحص دقيق بأنواع جميع البلاغات
- ✅ **فحص الصفحات المتقدم** - تحليل شامل للصفحات بأكملها
- ✅ **دعم الذكاء الاصطناعي** - تحليل ذكي ودقيق
- ✅ **قائمة تفاعلية** - واجهة سهلة الاستخدام بالعربية
- ✅ **نصائح الإبلاغ** - خطوات تفصيلية لضمان إزالة المحتوى
- ✅ **حفظ البلاغات** - تخزين سجل البلاغات السابقة
- ✅ **توافق Kali Linux** - يعمل بسلاسة على تيرمنل Kali

## أنواع المخالفات المكتشفة

1. 🔴 **كلام الكراهية** - Hate Speech
2. 🔴 **المحتوى العنيف** - Violence
3. 🔴 **المحتوى العاري** - Nudity/Sexual Content
4. 🔴 **التحرش والاستهداف** - Harassment
5. 🟠 **المعلومات المضللة** - Misinformation
6. 🟠 **البريد العشوائي** - Spam
7. 🟠 **عمليات الاحتيال** - Scams
8. 🔴 **إيذاء النفس** - Self-Harm
9. 🔴 **المحتوى غير القانوني** - Illegal Content
10. 🔴 **المحتوى الإرهابي** - Terrorism

## التثبيت

### المتطلبات
- Python 3.8+
- Kali Linux / Linux / macOS / Windows

### خطوات التثبيت

```bash
# 1. استنساخ المستودع
git clone https://github.com/retajs8mm-arch/facebook-content-checker.git
cd facebook-content-checker

# 2. تثبيت المكتبات المطلوبة
pip install -r requirements.txt

# 3. جعل البرنامج قابل للتنفيذ
chmod +x main.py
```

## الاستخدام

### تشغيل الأداة على Kali Linux

```bash
# الطريقة 1: مباشرة
python3 main.py

# الطريقة 2: باستخدام التنفيذ المباشر
./main.py

# الطريقة 3: مع root (إذا لزم الأمر)
sudo python3 main.py
```

## خطوات الاستخدام

### 1️⃣ فحص منشور

1. اختر `[1]` من القائمة الرئيسية
2. أدخل رابط المنشور
3. انتظر الفحص الشامل
4. اطلع على التقرير المفصل
5. اتبع خطوات الإبلاغ الموصى بها

### 2️⃣ فحص صفحة

1. اختر `[2]` من القائمة الرئيسية
2. أدخل رابط الصفحة
3. انتظر الفحص المتقدم (قد يستغرق وقتاً أطول)
4. اطلع على التقرير الشامل
5. اتبع التوصيات والخطوات

### 3️⃣ عرض البلاغات السابقة

1. اختر `[3]` لعرض جميع البلاغات المحفوظة
2. استعرض السجل الكامل

## استكشاف الأخطاء

### المشكلة: "ModuleNotFoundError"
**الحل:**
```bash
pip install -r requirements.txt
```

### المشكلة: "عدم عرض الأحرف العربية بشكل صحيح"
**الحل:**
```bash
export PYTHONIOENCODING=utf-8
python3 main.py
```

### المشكلة: "البرنامج لا يعمل على Windows"
**الحل:** استخدم Windows Subsystem for Linux (WSL) أو Kali Linux
